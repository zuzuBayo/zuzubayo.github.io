Sobre ZuzuBayo ♡

ZuzuBayo es un espacio creativo de productos digitales pensado para hacer las cosas un poco más bonitas, prácticas y especiales. Aquí encontrarás recursos para organizarte, crear, aprender y acompañar tus metas.

Preguntas frecuentes ♡

¿Es un producto físico?

No. Los productos de ZuzuBayo son digitales. No recibirás ningún artículo físico por correo.

¿Cómo recibo mi compra?

Después de completar y confirmar el pago de un producto disponible, recibirás el acceso de descarga correspondiente. El checkout también solicita un correo para la entrega.

¿Puedo imprimirlo?

Depende del producto. Revisa la descripción de cada recurso para confirmar su formato y el uso recomendado.

¿Puedo reutilizar las páginas?

Cuando el producto lo permita, podrás reutilizarlo para uso personal según la licencia incluida.

¿Qué licencia incluye?

Cada producto indicará claramente la licencia de uso correspondiente.

¿Necesito Canva?

No todos los productos requieren Canva. La página de cada producto indicará claramente si necesitas alguna herramienta específica.

¿Necesitas ayuda? ♡

Si tienes alguna pregunta sobre un producto, una descarga o una compra, puedes comunicarte con ZuzuBayo.
